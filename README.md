# SQL Case Studies

A collection of SQL case studies built around practical business problems and real-world-style datasets.

The projects focus on using SQL to clean, explore, analyze, and interpret data rather than simply writing queries. Each case study documents the business problem, analysis approach, key SQL techniques, findings, and relevant data-quality considerations.

## What You'll Find

* Business-oriented SQL analysis
* Data cleaning and validation
* Joins and aggregations
* CTEs and subqueries
* Conditional aggregation
* Window functions
* Rate, ratio, and trend analysis
* Duplicate and data-quality checks
* Business insights and interpretation

## Case Studies

Each project is organized separately with its own datasets, SQL queries, analysis notes, and findings.

More case studies will be added over time, covering different business domains and analytical scenarios.
